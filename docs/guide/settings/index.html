Android extras

A few Android-only conveniences

  • Hardware volume keys: while AVR Maestro is in the foreground, your phone's volume keys control the receiver's volume (using your Volume Step). Foreground-only; iOS doesn't allow this.
  • Home-screen widgets: Quick Control (power / volume / mute / source), Now Playing, and Status - all resizable, tap-only and auto-refreshing.
  • Backup & Restore: export every receiver, preset and preference to a JSON file and restore it on a new phone. The file holds no credentials or personal data beyond receiver IPs and your own preset names - safe to share.
Common questions

Settings FAQ

Can I change the app's theme and colors?
Yes - Light, Dark, Device or AMOLED (true black), plus TJ Mode where you pick any accent color and the app rebuilds its palette. You can also set Display/Widget size and customize navigation and tabs.
Can I back up my setup?
Yes - Settings, Backup exports every receiver, preset and preference to a JSON file; import to restore on a new phone. No credentials in the file, so it's safe to share.
Do the phone's volume keys control the receiver?
On Android, yes - while the app is in the foreground, your volume keys control the receiver's volume. iOS doesn't allow this.
